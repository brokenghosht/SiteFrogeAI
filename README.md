   ```bash
   npm install
   ```

2. **Start the local development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

   The production-ready output will be located in the `dist/` directory, ready to deploy to Vercel, Netlify, or Cloudflare Pages.
